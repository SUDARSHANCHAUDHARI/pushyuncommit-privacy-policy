# PushyUncommit — Privacy Policy

**Effective Date:** April 2026
**Last Updated:** April 2026
**Version:** 1.0.0

Published by **Sudarshan Tech Labs** | sudarshantechlabs@gmail.com

PushyUncommit is a developer tool that connects to a Python server you run on your own machine to show git repository status. No data is sent to any third-party server. SudarshanTechLabs collects no personal information.

---

## Data Collection

PushyUncommit collects **no personal data**.

| What we store | Where |
|---|---|
| Your local server URL | On your device only |

Everything else stays on your machine.
